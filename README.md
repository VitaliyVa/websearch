# websearch — пайплайн лідів

Пошук бізнесів у США з **укр/рос-мовними власниками** і **застарілими сайтами**.
На виході — Google-таблиця для продажників з оцінкою сайту, доказами мови та
складністю розробки, плюс веб-панель.

> **Перед тим як щось міняти — прочитай [NOTES.md](NOTES.md).**
> Тут описано, як користуватись; там — межі квоти (це реальні гроші), пастки,
> які вже коштували часу, і причини нетипових рішень.

## Що потрібно від тебе (чекліст)

### 1. Google Cloud

Створи **окремий** проєкт (не той, де інші продукти — якщо заблокують білінг, решта не постраждає).

1. https://console.cloud.google.com → новий проєкт
2. Прив'яжи платіжну картку — без неї Places API не вмикається навіть у безкоштовному тирі
3. **Обов'язково** постав Budget Alert на $20: Billing → Budgets & alerts
4. Увімкни чотири API (APIs & Services → Library):
   - **Places API (New)** ← саме New, не старий
   - **PageSpeed Insights API**
   - **Google Sheets API**
   - **Google Drive API**

### 2. Два API-ключі

APIs & Services → Credentials → Create credentials → API key

| Ключ | Обмеження | Змінна в `.env` |
|---|---|---|
| Places | API restrictions → Places API (New) | `GOOGLE_PLACES_KEY` |
| PageSpeed | API restrictions → PageSpeed Insights API | `GOOGLE_PSI_KEY` |

Обмеження ставити обов'язково — необмежений ключ, що витік, спалює бюджет за години.

### 3. Service Account для таблиці

1. IAM & Admin → Service Accounts → Create
2. Keys → Add key → Create new key → **JSON** → завантажиться файл
3. З файлу візьми `client_email` → `GOOGLE_SA_EMAIL`, `private_key` → `GOOGLE_SA_PRIVATE_KEY`
4. Створи порожню Google-таблицю
5. **Розшар її на `client_email` з правами Editor** — без цього скрипт отримає 403
6. ID таблиці з URL: `docs.google.com/spreadsheets/d/`**`ЦЕЙ_ID`**`/edit` → `GOOGLE_SHEET_ID`

### 4. Налаштування

```bash
cp .env.example .env    # заповни ключами
npm install
npx playwright install chromium   # для скріншотів і обходу bot-protection
```

## Запуск

```bash
# 1. Подивитись, які запити підуть у Google — БЕЗ викликів і без ключів
npm run lead -- discover --dry-run

# 2. Обережний старт: 20 задач замість 368
npm run lead -- discover --limit 20

# 3. Аудит сайтів — безкоштовно, свій HTTP
npm run lead -- audit

# 4. ПОДИВИТИСЬ РОЗПОДІЛ ДО ТОГО, ЯК СТАВИТИ ПОРОГИ
npm run lead -- stats

# 5. Мовний сигнал з відгуків — тільки для невизначених, їсть квоту
npm run lead -- reviews

# 6. PageSpeed + скріншоти
npm run lead -- enrich

# 7. У таблицю
npm run lead -- export
```

Або все підряд: `npm run lead -- run`

### Корисне

```bash
# Перевірити всі ключі й доступи ЖИВИМИ запитами (не просто наявність у .env)
npm run lead -- doctor

# Розібрати один сайт вручну: 0 викликів Google, нічого не пише в базу.
# Потрібно для підбору порогів і розбору спірних лідів з вкладки Manual review.
npm run lead -- inspect https://example.com --name "Назва бізнесу"

# Перепрогнати дешеві фільтри по вже зібраній базі — 0 викликів Google.
# Потрібно, коли змінив пороги в пресеті: не треба платити за discover заново.
npm run lead -- refilter

# Стан бази, розподіл скорів, витрати квоти
npm run lead -- stats
```

## Бюджет

| SKU | Ціна | Безкоштовно/міс | Де використовується |
|---|---|---|---|
| Text Search **Enterprise** | $35 / 1000 | **1 000** | `discover` — бо `websiteUri`, `rating`, `userRatingCount` це Enterprise-поля |
| Place Details **Enterprise + Atmosphere** | ~$40 / 1000 | **1 000** | `reviews` — мовний сигнал з відгуків |
| PageSpeed Insights | безкоштовно | 25 000 / добу | `enrich` |

Пілот (3 метро) вкладається у **$0**: ~650 запитів Text Search + ~350 Place Details.

Скрипт **сам зупиняється** на лімітах з пресета (`budget` у `config/presets/*.json`).
Вийти за них можна лише явно: `--allow-paid`.

## Як працює воронка

```
L0  discover   Places Text Search: етнічні запити + гео-щільні по діаспорних районах
L1  (в discover) дешеві фільтри: живість, адреса США, виключені країни — 0 API
L2  audit      фетч сайту: мова, Viber, техстек, viewport, TLS, sitemap → оцінка 1-10
L3  reviews    мова Google-відгуків — ТІЛЬКИ для тих, кому сайту не вистачило
L4  enrich     PageSpeed + скріншоти + строгий поріг оцінки сайту
L5  export     Google Sheets, 4 вкладки
```

**Чому саме такий порядок.** Сайтові сигнали безкоштовні, відгуки їдять квоту.
Тому якщо сайт уже дав ≥70 балів — відгуки не запитуються взагалі.
Квота зберігається для тих, кому вона справді потрібна: асимільованого бізнесу
з англомовним сайтом, де відгуки — єдиний спосіб побачити мову власника.

### Два режими пошуку

| Режим | Приклад | Що ловить |
|---|---|---|
| `ethnic` | `ukrainian dental office in Chicago IL` | Ті, хто сам себе позиціонує етнічно. Висока точність |
| `geo-dense` | `dental office near Brighton Beach` | Асимільований бізнес з англомовною назвою — саме той, у кого є гроші |

### Мовні сигнали за силою

| Сигнал | Бали | Чому |
|---|---|---|
| Робоча `/ru` або `/uk` версія сайту | 40-45 | Свідоме рішення обслуговувати слов'яномовних клієнтів |
| Кирилиця на сторінці (укр/рос гліфи) | 35-40 | `і ї є ґ` vs `ы э ъ ё` — розрізняє мови |
| **Viber у контактах** | 35 | Проникнення в США ~0%, у діаспорі тотальне. Працює навіть на англомовному сайті |
| Accept-Language віддає кирилицю | 35 | Ловить Next/Nuxt/Django-сайти без `/ru` в URL |
| Відгуки uk/ru ≥25% | 20-45 | Єдиний сигнал для повністю асимільованого бізнесу |
| Назва: `ukrainian`, `slavic`, `-енко`, `-чук` | 8-30 | |

**Жорсткі виключення:** сербські гліфи `ђјљњћџ`, болгарський патерн `ъ`, домени `.ru/.by/.su`, телефони `+7`, назви з `polish/serbian/czech/bulgarian`.

## Google-таблиця

**Колонки A..W — машинні.** Скрипт їх перезаписує при кожному прогоні.
**Колонки X..AA — людські** (Статус / Хто веде / Дата контакту / Коментар).
Скрипт пише виключно в діапазон `A:W`, тому нотатки продажників **фізично не можуть бути затерті**.

> **Якщо міняєш склад машинних колонок** — спершу `npx tsx scripts/migrate-columns.ts`,
> потім онови `Code.gs` у редакторі Apps Script.
>
> Людські колонки поїхали з `W..Z` на `X..AA`, коли додали «Опис для продажника».
> Старий Code.gs мав номер колонки статусу зашитий числом (`COL_STATUS = 23`) і після
> зсуву писав би статус поверх опису — мовчки, при кожній зміні статусу. Тепер він
> шукає ці колонки за назвою заголовка, тож наступна зміна розкладки нічого не зламає.

**Складність розробки** подається зірками 1-5, а не годинами. Години лишились у БД
(`site_audits.hours_min/max`) для внутрішнього планування, але в таблицю не йдуть:
діапазон «22-33 год», сказаний уголос, миттєво перетворюється на ціну, якої ще ніхто
не рахував, і зводить розмову до трудовитрат замість цінності.

**Опис для продажника** генерується детерміновано з даних аудиту (`src/score/brief.ts`):
що за бізнес, що за сайт, що зламано, за що зачепитись. Правило модуля — якщо даних
нема, речення не з'являється: вигадана деталь коштує дорожче за відсутню, бо клієнт
одразу чує, що дзвонить людина, яка сайт не відкривала.

Вкладки:
- `Leads` — мовний скор ≥70, сайт ≤6/10. Відсортовано: найгірший сайт + найбільше відгуків зверху
- `Manual review` — скор 40-69, або сайт не вдалось прочитати (bot-protection)
- `NO_SITE` — тільки Facebook/Instagram. Інший оффер, інша ціна
- `Rejected` — щоб не переобробляти вдруге (експортується лише з `--with-rejected`)
- `Meta` — дата прогону, статистика, витрати квоти

Оцінка сайту підсвічена: зелений 1-3 (гарячий лід), сірий 8-10.

## Що НЕ автоматизується

| Проблема | Обсяг | Що робить скрипт |
|---|---|---|
| Cloudflare / bot-protection → 403 | 5-10% | Пробує Playwright з реальним UA. Якщо не вийшло — `Manual review`, **не** відсів |
| Wix/Squarespace з JS-рендером | 10-15% | Playwright-fallback автоматично |
| **Email відсутній** | ~45% | Places API email не дає взагалі. Парсимо `mailto:`, Cloudflare-обфускацію. Решта — продажник дзвонить |
| Мовний скор 40-69 | 10-20% | Вкладка `Manual review` + `inspect <url>` для розбору |

## ToS Google

Maps Platform Terms забороняє *«copying and saving business names, addresses, or user reviews»*.
Що зроблено для пом'якшення:

1. `place_id` зберігається безстроково — це офіційно дозволено
2. Назва/адреса/координати мають `google_fetched_at`, TTL 30 днів
3. **Тексти відгуків не запитуються і не зберігаються** — field mask бере лише `languageCode`, `rating`, `publishTime`, а в базу йдуть тільки агрегати
4. Все, що зафетчено з сайту компанії (техстек, email, скор), — наше, без обмежень
5. Окремий GCP-проєкт

Це не робить схему стерильною, але прибирає найгрубіші порушення.

## Структура

```
config/
  metros.json              12 метро США з діаспорними районами (координати + радіуси)
  niches.json              27 ніш по тирах A/B/C + етнічні маркери
  presets/                 пороги, бюджети, які метро активні
src/
  sources/places.ts        Places API (New), field masks з нотатками про SKU
  sources/queries.ts       розгортання конфігу в пошукові задачі
  detect/                  мова, назва, техстек, структура, контакти, пробінг
  audit/site.ts            оркестратор аудиту одного сайту
  score/                   quality (1-10), hours, owner (мовний скор)
  enrich/                  PageSpeed, скріншоти
  export/                  Google Sheets, схема колонок
  commands/                CLI-команди
  db/                      node:sqlite (вбудований у Node 24, без нативних збірок)
```

Стан у `data/leads.db`. Кожна стадія має власний прапорець — **перезапуск будь-якої команди безпечний і не платить двічі**.
